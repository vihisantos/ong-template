## Sobre

**LoveFlow** e um template de site moderno e acessivel para ONGs e organizacoes do terceiro setor. Construido com React 19 e Vite, oferece design responsivo, conformidade com WCAG AAA e otimizacao para mecanismos de busca.

---

## Tech Stack

| Tecnologia | Proposito |
|---|---|
| **React 19** | Biblioteca de interface |
| **TypeScript** | Tipagem estatica |
| **Vite** | Build tool e dev server |
| **Tailwind CSS v4** | Estilizacao utilitaria |
| **React Router 7** | Roteamento SPA |
| **Lucide React** | Iconografia |

---

## Funcionalidades

- Conformidade WCAG AAA (acessibilidade)
- SEO otimizado
- Design responsivo
- Componentes reutilizaveis
- Performance e carregamento rapido
